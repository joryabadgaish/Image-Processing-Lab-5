# Image-Processing-Lab-5

## Description
Notebook covering spatial filtering with OpenCV: unsharp masking, box, Gaussian, Laplacian, median, and bilateral filters.

## Requirements
    pip install opencv-python numpy matplotlib scikit-image

## How to Run
Open the notebook in Jupyter or Colab and run all cells. No image files needed (the astronaut image comes from `skimage.data`).
